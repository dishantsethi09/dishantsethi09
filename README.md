## Featured Project

### FestX — College Event Management System

A full-stack event management platform built for college events with separate **Student** and **Organizer** portals.

**Key Features:**

- Dual-portal system for students and organizers
- RBAC authentication using Clerk
- Scalable MongoDB Atlas schemas
- Cloudinary media hosting
- CI/CD deployment on Vercel
- Real-time capacity tracking
- Automated organizer verification
- UX and API performance optimizations
- Documentation and onboarding guides

**Tech Used:**

`Next.js` `React.js` `TypeScript` `Tailwind CSS` `Node.js` `Express.js` `MongoDB Atlas` `Cloudinary` `Vercel`
